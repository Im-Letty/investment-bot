業者への依頼に向けた形の読取見本

村の立体データの平面投影

架空の配置から既存コードが作る立体パーツを読み、真上から見た線にします。元の位置と、コードが調整した位置も確認できます。

対象は6つの場所に属する Mesh の格納データです。木と花の原画は読み込まず、絵の要素を範囲の一覧に残します。衝突・移設の可否や工事は未判定です。

読取のコードを準備しています。

線は格納された三角形の投影です。高さ Y は読取記録に含みます。表示用の非表示フラグだけで、まとめ描画用の元パーツを除いていません。

読取範囲

原画は未読込です。絵の厚み、範囲外の地形、歩行経路や干渉、本人の保存内容はこの見本の対象に含みません。

    座標と範囲の読取記録

    ここには各場所の総数と位置、先頭3パーツの例を表示します。各例の材質区分も先頭3件までです。全頂点・三角形と区分は、切り離して凍結した読取結果に保持します。

    記録中の drawRange.count の null は、描画数に上限指定がないという符号です。
