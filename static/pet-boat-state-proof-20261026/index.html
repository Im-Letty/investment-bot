航路位置の保存と停止復元

既存の船体と短い航路を使い、この独立見本だけの位置を保存・復元します。保存ボタンで更新し、再表示では停止したまま始まります。

通常ゲームの保存・自由航行・乗降との連続操作は未接続です。乗船済みの参照から始め、既存の乗降成功を作り直しません。参照は既存の紫の baby 2D 表示 1 case のみ。本人の選択中キャラとの連動、全身体積・全角度の装着や接触の完成を示しません。川底は未定義です。
