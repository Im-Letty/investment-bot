# Shareholder benefits calendar

Initial reviewed catalogue: 2026-09-25. This is a manually reviewed initial selection,
not an exhaustive catalogue, popularity ranking or automatic benefit-data updater.

Sources:
- https://www.matsukiyococokara.com/ir/stockinfo/benefits/ : September/March-end record dates,
  100–499 shares, 2,000 points or donation, application needed; prescription exclusions.
- https://info.monex.co.jp/news/2026/20260917_03.html : September 2026 record date and
  September 28 last cum-rights trading date. Only this explicitly verified date is seeded.
- https://www.kddi.com/corporate/ir/individual/stockholder/ : 2026 programme,
  200 shares and continuous registration of the same shareholder number; one-year minimum,
  2,000 yen equivalent for one to under five years; 2026 applications closed August 31.
  No next-year event is inferred. Kept in the undated programme panel with that limitation.

Update the verified date only after re-reading the official programme, including changes,
termination, share splits and continuity conditions. Never derive benefit eligibility from
an existing dividend event. Explicit future events need their own checked deadlines.

UI: benefits sits between dividends and favorites; uses existing theme and responsive grid.
No additional network requests on tab changes; dates are independent of dividend data.
